## 二、关键判定节点的逐项解析

### N1 案件分类

- 含民事请求（"退一赔十 1000 元"） + 行政请求（"依法查处""责令停止违法行为"） + 程序请求（"书面回复""告知调解员信息"）→ **M-CRP**（Mixed · 投诉+举报+程序）
- 案件 A 与案件 B 都有程序请求（书面回复），但 B 更复杂（多了平台管辖的特别请求）

### N2 拆件结果（关键）

```
原信
├─ 拆出 T-1【投诉轨】退一赔十（民事型）
│      主体：举报人 ↔ 销售者（光泽县寨里镇优鲜百货商行）
│      时限：7 工作日决定受理（令121号第24条）
│
├─ 拆出 C-1【查处轨】标签违法（标签类）
│      指控：执行标准错误（GB 7098-2015 误用于袋装产品）
│      责任主体：销售者 + 标称生产商
│      依据：食安法 67(五) → 125 条 1 款 / 2 款
│
└─ 拆出 C-2【查处轨】无证分装（资质类）
       指控：涉嫌未取得分装资质
       责任主体：实际分装者（生产商）
       依据：食安法 35 条 + 122 条
       ⚠ 需现场核查生产许可明细、实际生产工艺
```

**拆件依据**：
- C-1 与 C-2 **责任主体不同**：标签违法，销售者与生产者均为责任主体；无证分装仅实际分装者为责任主体
- C-1 与 C-2 **证据要求不同**：C-1 看产品标签即可定；C-2 需现场核查、查阅生产许可
- C-1 与 C-2 **法律依据不同**：C-1 走 125 条；C-2 走 122 条未经许可从事食品生产经营
- C-1 与 C-2 **处理周期不同**：C-1 可能快速定性为瑕疵；C-2 必须实质核查，90 日办案

**易错输出**：
- ❌ 全部并为一件"C-1"处理（仅查标签）
- ❌ 全部并为一件"C-1"处理（仅查资质）
- ❌ 漏掉 T-1，只处理举报
- ✅ 拆为 T-1 + C-1 + C-2 三件

### N3 管辖（关键 · 案件 B 的核心难点）

| 选项 | 是否正确 | 说明 |
|---|---|---|
| 厦门市思明区局 | ❌ | 举报人所在地 ≠ 被举报人住所地 |
| 微信平台经营者住所地 | ❌ | 旧《暂行办法》第 12 条规定（已废止） |
| 销售者注册地光泽县局 | ❌（部分对） | "住所地"通常指**主要办事机构所在地**；个体工商户以登记注册地为住所地，**多数情况即注册地** |
| **平台内经营者的住所地县级局** | ✓ | 令121号第13条（注：原办法称"实际经营地"；**新办法已改为"平台公示地址"**） |

**新规关键变更**（令121号第13条 vs 旧《暂行办法》第12条）：

| 对比项 | 旧《暂行办法》第12条 | **令121号第13条（2026-04-15施行）** |
|---|---|---|
| 平台内经营者管辖地 | **实际经营地** | **平台公示地址** |
| 实际经营地与公示地不一致 | 按实际经营地 → 可能无管辖 | 按公示地 → **有明确管辖** |
| 无实际经营场所 | 可能产生管辖真空 | 按公示地址 → 解决真空 |

**本案**：
- 平台店铺「闽北山货直供」**公示地址**：福建省南平市光泽县寨里镇**村**组
- 销售者**注册地址**：福建省南平市光泽县寨里镇**路 12 号
- 实际经营地：无
- **新规下** → 一律按**平台公示地址** → 光泽县寨里镇
- → **光泽县市场监督管理局**管辖

**举报人提交路径**：
- 举报人选择**向南平市级局**提交履职申请
- 市级局应在 **7 个工作日内**（令121号第24条 + 第 4 条）决定受理 / 移送 / 不予受理
- 预期路径：南平市局 → 移送光泽县局
- 移送后由光泽县局在 15 个工作日内完成核查（令2号第18条），再决定是否立案

**易错输出**：
- ❌ 判为厦门市思明区局管辖（错：未识别第13条变更）
- ❌ 判为平台经营者所在地管辖（错：旧《暂行办法》规则）
- ❌ 判为"管辖不明、暂不受理"（错：第13条已解决此问题）
- ✅ 判为光泽县局管辖；记录举报人选择向市级局提交，启动 7 工作日答复

### N6 瑕疵判定

| 指控（C-1） | 是否落入令49号第37条六种情形 | 结论 |
|---|---|---|
| 执行标准 GB 7098-2015 用于袋装熟肉 | 落入 37条(一)「文字不规范」，但本质是**执行标准错配** | **瑕疵**（形式上不规范、内容上张冠李戴） |

**易错输出**：
- ❌ 认定为"不符合食品安全标准" → 立案查处 → 商家被罚 5000–5 万
  - 注：执行标准错配可能导致**违反标准化法第25条**（销售不符合强制性标准的产品），但这是另一个法律关系（**标准化法**而非**食品安全法**）。本案以食品安全视角切入，**默认按食安法定性**。
- ❌ 认定为"虚假内容"（与第71条"标签不得含有虚假内容"混淆）
- ✅ 认定为**瑕疵**（执行标准是文字标注问题，落入 37条一）→ 责令改正

### N7 C-2 无证分装的处理

⚠️ **A3 禁止自动化**。智能体**不得**直接定性为"立案"或"不立案"。

**必须现场核查**：
1. 调取南平市延平区锦鸣食品有限公司的食品生产许可证（SC10935070200158）许可明细
2. 核查实际生产工艺是否为分装
3. 调取生产记录、进货记录、销售记录
4. 询问当事人
5. 必要时委托检验机构对样品检验

**可能的定性结果**：
- 若许可类别齐全但生产工艺实际为分装 → 责令改正 + 处罚（按《食品生产许可管理办法》第49条）
- 若完全未取得分装许可 → 食安法 122 条：没收违法所得 + 货值金额罚款 + 没收物品
- 若举报人"无实际经营场所"成立 → 同时启动**撤销登记**程序（依《市场主体登记管理条例》）

**预期处理周期**：
- 核查：15 个工作日（令2号第18条），可延长 15 工作日
- 立案后办案：90 日（令2号第64条）
- 复杂案件：经本机关负责人批准可延长 30 日
- 涉嫌犯罪移送公安：+ 30 日（公安决定是否立案）

### N8 T-1 调解结果

| 节点 | 处理 |
|---|---|
| 7 工作日决定是否受理 | **受理**（要件齐备，第16条 7 项未触发） |
| 发出调解通知 | 通知销售者参与调解 |
| 商家明确拒绝 | 落入第23条第（三）项「被投诉人明确拒绝调解」 |
| 终止调解决定 | 7 个工作日内作出（令121号第23条第2款） |
| 民事争议引导 | 告知举报人可向法院起诉或申请小额诉讼 |

**易错输出**：
- ❌ 商家说"代卖"=拒绝 → 立即终止 → **不发出调解通知**（错：应先通知并由商家在通知程序中明确表示）
- ❌ 直接判"不支持十倍赔偿" → **不启动调解程序**（错：先程序后实体）
- ✅ 发出调解通知 → 商家在通知后 5 个工作日内未回复或明确拒绝 → 终止调解 → 告知民事救济路径

### N9 举报奖励

- 货值 19.80 元 + 涉及**标签瑕疵** + **可能**涉及无证生产
- 若 C-1 仅为瑕疵 → 不予奖励（货值小、属瑕疵类）
- 若 C-2 查实为无证生产 → 可能符合奖励条件，但需查实后另行评定
- **预期：暂不给予奖励**（待 C-2 查实后再定）

### 举报人保密

- 来电明确要求"请把我的姓名、电话、地址保密"
- 依据第36条：**调解过程中必需信息除外**
- 在 C-1 查处轨：举报人信息**不向商家披露**（商家是核查对象）
- 在 T-1 调解轨：调解过程中**必需**告知对方当事人（消费者 vs 销售者），但**电话、地址、身份证号**仍可脱敏
- 智能体处理：标记「保密等级 3 - 全程保密（除调解必需字段）」

### 新线索分流

- 来电中"商家在光泽县其实根本没有实际经营场所" → **新线索**
- 应：
  1. 转核查轨（**增项并入 C-1 或 C-2 的核查清单**）
  2. 同时建议**市场主体登记管理部门**核查（撤销登记线索）
- ⚠️ 不得让举报人补充的"无经营场所"主张影响"管辖判定"——管辖是**程序**问题，"无经营场所"是**实体**问题，两者独立
