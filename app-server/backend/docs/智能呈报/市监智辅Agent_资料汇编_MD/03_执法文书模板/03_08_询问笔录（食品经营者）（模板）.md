被询问人：   看清楚了。  
问：我们依法就 你销售的产品 有关问题进行调查，请予配合。依照法律规定，你有权进行陈述和申辩。如果你认为调查人员与本案有直接利害关系或者有其他关系可能影响公正执法的，依法有申请回避的权利，你是否申请调查人员回避？  
答：不申请调查人员回避。  
问：你应当如实回答询问，并协助调查，不得拒绝或者阻挠。 你是否明白？  
答：明白。  
问：我局向你出示被投诉举报的产品是否为你单位销售？  
答：是我单位销售。  
问：该产品是从哪里购进的？是否进行进货查验及台账记录？  
答：该产品是我单位从                  购进的。购进时我查验了购进单位的资质和产品的合格证明，也进行了台账记录。  
问：该产品标签标识存在被举报问题，你是否知悉和认可？  
答：因为对法律法规和执行标准不熟悉，我单位本来不知晓食品标签存在问题，你局来检查后我局就知道了，对被举报的问题我单位是认可的。  
问：你单位对被举报产品购进了多少批次和数量？销售了多少？购进成本和销售单价分别是多少？‌  
答：我带了进货台账和销售记录，你单位可以查看记录台账。  
问：你单位知悉了标签标识存在的问题，是否采取相关措施进行改正？  
答：采取了，我单位对产品进行了召回和整改，有召回公告和整改报告。  
问：你单位是否收到被举报产品存在食品安全问题的反馈？  
答：没有收到过。
