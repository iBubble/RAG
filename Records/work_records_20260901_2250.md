# 2026-09-01 22:50 新增“分拣填报”与“案情研判”双轨智能表单系统

## 业务背景
为贯彻市场监管执法标准，依据《市场监督管理投诉举报处理办法》（总局令第121号）第9条“分别处理”原则及《市场监督管理行政处罚程序规定》（总局令第2号），用户要求在导航栏“智能助手”和“AI表格”之间增加“分拣填报”与“案情研判”两个顶级 Tab 项，以现代仿真 A4 纸张卡片网格样式展示文书，并基于大模型实现智能推荐、互斥过滤与 RAG 自动填报。

## 核心实现细节
1. **后端路由与推理引擎 (`api/triage_judgment.py`)**：
   - 挂载 `GET/POST /api/projects/{project_id}/triage/recommend` 与 `GET/POST /api/projects/{project_id}/judgment/recommend`；
   - 动态加载 `docs/智能呈报` 目录下的《规范》、《设计方案》等法条依据，并提取当前项目案卷材料文本；
   - 严格落实互斥业务规则：《投诉登记表》vs《举报登记表》互斥二选一；《投诉受理决定书》vs《投诉不予受理决定书》互斥二选一；《行政处罚决定书》vs《不予行政处罚决定书》互斥二选一；
   - 推荐结果与分析摘要持久化保存至 `DATA_DIR/triage` 和 `DATA_DIR/judgment`，实现“开始分拣/重新分拣”状态切换与秒级秒读恢复。
2. **前端组件体系**：
   - **`PaperFormCard.tsx`**：像素级对齐用户提供的“图二”现代纸质公文微缩卡片，呈现 A4 纸张比例、精致阴影、骨架装饰线、彩色提示块、“已填报/待填报”状态徽标与悬停浮感动效；
   - **`FormFillModal.tsx`**：全屏高保真公文填报弹窗，内嵌 Tiptap 实体黑边框编辑器，支持一键 RAG 智能填表、手动修改、保存归档、重新填写、Word 导出及标准 A4 打印；
   - **`IntakeSortingPanel.tsx` 与 `CaseJudgmentPanel.tsx`**：分别作为“分拣填报”与“案情研判”的主面板，集成控制台、AI 判定意见条与卡片网格布局；
   - **`App.tsx`**：导航栏更新为 `智能助手` | `分拣填报` | `案情研判` | `AI表格` | `定制文档`，并无缝挂载对应视图。
3. **构建与热生效**：
   - 容器内完成 `npm run build` 生成最新静态包 `index-v4-BslPvCZM.js`；
   - 重载 `genrag-backend`、`genrag-frontend` 与 `genrag-gateway`，实机调用验证大模型推理精准闭环。
