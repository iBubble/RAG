# 工作记录 - 2026-09-11 23:48

## 任务背景
用户需要在后台增加大模型多服务商配置中心（类似离线政务引擎 API 配置），支持各类配置保存后在切换模型引擎服务商时自动调出回填专属配置，兼容本地 Ollama 与外部兼容 Gateway（如 `http://40dd.shop:8001/v1`）；同时要求多模态视觉识别大模型作为大模型配置页面下方的完全独立配置项目，并在系统全链路智能巡检结果弹窗中展示当前生效的主力与多模态模型端点与信息。

## 核心架构与实施详情
1. **统一配置仓与服务商隔离** [llm_config.py](file:///Users/gemini/Projects/Own/RAG/app-server/backend/core/llm_config.py)：
   - 在 SQLite `system_settings` 中持久化 `llm_providers_config` 与 `vision_llm_config`；
   - 预设 `DeepSeek-R1`、`通用 兼容 Gateway`、`Ollama 本地私有化部署`；
   - 实现轻量探针测试接口 `test_llm_connection`（返回延迟毫秒与诊断信息）与端点归一化函数。
2. **多服务商与视觉管理 API** [api/admin.py](file:///Users/gemini/Projects/Own/RAG/app-server/backend/api/admin.py)：
   - `GET /api/admin/llm/providers`：获取主力与视觉模型全量配置；
   - `POST /api/admin/llm/providers`：保存主力服务商配置并热激活；
   - `POST /api/admin/llm/vision-config`：保存多模态视觉识别模型独立配置；
   - `POST /api/admin/llm/test-connection`：Gateway 连通性快速探针。
3. **双模自适应流式引擎** [llm_engine.py](file:///Users/gemini/Projects/Own/RAG/app-server/backend/core/llm_engine.py)：
   - `_stream_ollama_inner` 动态判定端点协议，自动识别 OpenAI-compatible Chat Completions SSE 与 Ollama 原生协议；
   - 统一过滤 `<think>` 思考标签，无缝兼容打字机流式输出。
4. **多模态视觉抽取适配** [vision_extractor.py](file:///Users/gemini/Projects/Own/RAG/app-server/backend/core/extractors/vision_extractor.py)：
   - 支持独立第三方视觉端点（如 `http://40dd.shop:8000/v1`, `qwen3-vl-32b-awq`），支持带有 base64 图像的多模态 payload；
   - 维持 Tesseract 本地 OCR 自动降级链路。
5. **全链路状态巡检联动** [api/generate.py](file:///Users/gemini/Projects/Own/RAG/app-server/backend/api/generate.py) 与 [App.tsx](file:///Users/gemini/Projects/Own/RAG/app-server/frontend/src/App.tsx)：
   - `/api/llm/status` 透传当前生效的主力与多模态端点和模型；
   - 右上角全链路智能巡检结果弹窗优雅分行展示端点地址、服务商及模型名。
6. **前端双卡片独立控制面板** [LLMProviderSettings.tsx](file:///Users/gemini/Projects/Own/RAG/app-server/frontend/src/components/Admin/LLMProviderSettings.tsx) 与 [AdminLayout.tsx](file:///Users/gemini/Projects/Own/RAG/app-server/frontend/src/components/Admin/AdminLayout.tsx)：
   - 还原离线政务引擎高质感 UI；
   - 上方卡片控制核心推理大模型，下方独立卡片控制多模态视觉大模型；
   - 各自配备专属【保存配置】与【测试连通性】按钮。
